# Changelog

## 0.1.0 - 2026-01-05
- First public npm release of `morphing-toc`
- Ships `MorphingToc` component with configurable colors, sizes, and hover morph animation
- Exposes `useTocItems` hook and `scrollToSection` helper for custom TOC implementations
- Builds include `"use client"` directives and bundled type declarations
